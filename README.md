DMBI Experiment 5 – Bank Customer Churn System
Experiment Title
To Implement Classification Algorithms (Decision Tree and Naïve Bayes' Algorithms) Using Python – Bank Customer Churn System
Aim
To implement Decision Tree and Naïve Bayes classification algorithms using Python on the Bank Customer Churn System dataset and compare their performance.
Theory
1. Decision Tree
A Decision Tree is a supervised machine learning algorithm used for classification and regression. It represents decisions in a tree-like structure consisting of a root node, internal nodes, branches, and leaf nodes. It divides the dataset based on selected attributes and predicts the class of a given instance.
2. Naïve Bayes
Naïve Bayes is a supervised classification algorithm based on Bayes' theorem. It calculates the probability of an instance belonging to different classes and predicts the class with the highest probability. It assumes that features are conditionally independent given the class label.

Bayes' theorem:

P(A|B) = [P(B|A) × P(A)] / P(B)
3. Model Evaluation
Classification models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
The dataset is imbalanced, so accuracy should not be considered alone. Recall and F1-score for class 1 (Exited) are important.
Dataset Overview
- Dataset name: Bank Customer Churn (Churn_Modelling.csv)
- Number of instances: 10,000
- Original attributes: 14
- Target attribute: Exited
- Target classes: 0 – Stayed; 1 – Exited
Important attributes include CreditScore, Geography, Gender, Age, Tenure, Balance, NumOfProducts, HasCrCard, IsActiveMember, and EstimatedSalary. RowNumber, CustomerId, and Surname are identifiers and are removed before model training.

The objective is to predict whether a bank customer is likely to leave the bank based on demographic, financial, and account-activity information.

In the recorded run, Naïve Bayes achieved slightly higher overall accuracy than Decision Tree. This is important because the dataset is imbalanced and identifying churned customers is a key objective.
